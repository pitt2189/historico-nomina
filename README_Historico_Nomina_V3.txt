PROGRAMA HISTÓRICO DE NÓMINA V3

Incluye:
- Histórico acumulativo.
- Carga semanal desde Excel.
- Evita duplicados.
- Búsqueda por número de nómina.
- Consulta por concepto y periodo.
- Cambios del trabajador.
- DETECTOR DE TRABAJADORES AFECTADOS entre dos periodos.
- Identificación de conceptos que provocaron la disminución.
- Comparativo detallado de periodos.
- Ranking de mayores pérdidas.
- Respaldo manual de la base histórica.

Requisitos:
pip install streamlit pandas openpyxl

Ejecutar:
streamlit run app_historico_nomina_v3.py

La base histórica se guarda en:
historico_nomina.db

Los respaldos se guardan en:
backups_historico/
